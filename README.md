# Discipline — Native Android MVP

Native Kotlin Android app. No HTML, WebView, or web wrapper.

Included:
- Onboarding
- Today / Calendar / Statistics / Settings
- Add, edit, delete habits
- Local persistence using SharedPreferences + JSON
- Daily completion score
- Calendar score colors
- Basic 80% streak
- Dark UI
- Android 26+ / target SDK 34

Open the `Discipline` folder in Android Studio and build the debug APK.

Expected APK:
app/build/outputs/apk/debug/app-debug.apk

Note: this generated package intentionally keeps the MVP dependency-light so it is easier to build.
